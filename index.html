    个人信息完整交互

    每个功能独立连线；先查看目标页面，再阅读旁边说明。画面保留完整内容，可横向滚动查看。

    01 · 首页入口与个人信息

    首页进入个人信息；等级徽章的完整交互见本分类第04项。

    页面入口与退出

    1. 1、点击首页“个人信息”打开个人页。
    2. 2、右上角×或安卓返回键回到首页；
    3. 3、头像、昵称、已获成就和统计不清空。

    统计与等级入口

    1. 1、星星显示连续通关打卡天数；
    2. 2、中间分两行展示累计登录天数与最高连胜纪录，历史最高不随失败清零。
    3. 3、蓝色飘带显示主线关卡。
    4. 4、等级徽章显示当前玩家等级，点击打开经验获取介绍。
    5. 5、完整交互见本分类第04项。

    成就与固定区域

    1. 1、仅连续登录、累计登录、每日十关、六角征程、一次过关、彩片清扫。
    2. 2、卡片从上到下为名称、图标、等级、进度条；
    3. 3、当前值／目标值显示在进度条内。
    4. 4、内容区滚动，页头与广告位不遮挡列表。

    02 · 更换头像

    点击头像，在头像下方展开带指向角的选择对话框；点击选项立即保存并自动收起。

    打开与选择

    1. 1、点击个人信息中的头像，在头像下方展开对话框，指向角对准头像。
    2. 2、8个头像按4×2展示；
    3. 3、选中项高亮，点击后立即更新个人头像并自动关闭对话框。

    布局与滚动

    1. 1、顶部显示“头像”，下方为头像选项。
    2. 2、个人信息页面保留在背景；
    3. 3、对话框不重复展示头像预览和用户名，选项超出可用高度时上下滚动。

    关闭与保存

    1. 1、选择任意头像后自动收起，点击当前已选头像也收起；
    2. 2、点击框外同样收起。
    3. 3、回到个人页并恢复头像入口焦点，保留已选头像。

    03 · 昵称编辑与系统键盘

    从昵称进入编辑，确认或失焦保存；校验失败保留原昵称。

    进入与输入

    1. 1、点击昵称显示输入框，填入原昵称、选中已有内容并唤起系统键盘；
    2. 2、最多22字符。
    3. 3、编辑时不遮挡头像、统计和返回入口。

    保存与空值处理

    1. 1、点击键盘“完成”、按回车或输入框失焦时去除首尾空格并保存。
    2. 2、空字符串、纯空格不覆盖旧昵称；
    3. 3、普通文本与表情遵循原有字符限制。

    返回与数据同步

    1. 1、完成后恢复昵称文本，不改变头像、成就或统计。
    2. 2、保存结果通过昵称变更事件交给宿主；
    3. 3、再次进入编辑读取最新昵称。

    04 · 等级徽章与经验说明

    点击等级徽章展开带指向角的经验介绍对话框；只点击框外收起。

    点击等级徽章

    1. 1、点击个人页等级徽章，在徽章下方展开带指向角的对话框。
    2. 2、连续点击只打开一次，背景不响应。

    经验获取介绍

    1. 1、对话框不显示标题，说明合并为一句：登录和推关获得经验，连续打卡和连续胜利获得经验加成。
    2. 2、英文使用“day streak”与“win streaks”，两者及“multiplied XP”均用主题强调色加粗突出；
    3. 3、不显示具体经验、倍率或进度数值。

    关闭及数据保护

    1. 1、只点击对话框外部收起说明。
    2. 2、浏览说明不会发奖、扣经验或改变打卡。

    成就获得与领取

    登录或通关达标后自动展示。多项成就按配置顺序、同系列按等级升序逐个领取；全部完成后返回来源页面。

    获得与展示

    1. 1、达标时已获得对应成就等级，领取页展示祝贺；
    2. 2、中间从上到下为成就名称、徽章、Lv等级（如Lv1），不显示日期。
    3. 3、名称、徽章与等级从左侧滑入，展示后再出现“点击继续”。
    4. 4、领取成功后向左滑出，再展示下一项；
    5. 5、动画期间不响应领取。
    6. 6、没有关闭按钮。

    多个成就与跨级

    1. 1、同一次登录或通关达到多个成就，按配置顺序逐个展示；
    2. 2、同系列跨多级也逐级展示。
    3. 3、入场保护防止连点跳过；
    4. 4、全部领取后回到原首页或结算，下一关由用户主动点击。

    03 · 连胜、打卡与日期规则

    当前连胜

    • 新账号 currentWinStreak = 0。新主线有效胜利后 +1，再根据更新后的值读取 W；历史最高连胜同步取最大值。

    05 · 结算顺序与重复处理

    每日登录

    1. 有效登录时读取权威日期与账号记录，先校验是否漏掉完整一天打卡；已断卡则将 dayStreak 归 0。
    2. 检查账号当天登录奖励是否已提交。已提交返回首次结果，不按新档位重算。
    3. 未提交则读取当前连续打卡天数计算 D，入账 loginXp = 50 × D。记录 day_streak_at_login、D 与奖励结果，按第 04 节配置表更新等级；经验、当天领取标记及流水一致提交。
    4. 登录本身不增加打卡天数。当天后续通关使 D 提高时不补差、不再次领取，后续登录奖励按届时校验后的天数结算。
    5. 界面展示提交成功的经验与等级，重登、切后台、重启均不重复发奖。

    新主线关卡成功

    1. 校验账号、对局唯一 ID、稳定关卡 ID、可信时间及有效结果；按账号的对局顺序处理。
    2. 检查对局是否已处理。已处理直接返回原快照，不再次变化连胜、打卡或经验。
    3. 确认该账号该关具备首次通关资格，已领取过该稳定关卡首通经验的请求不再发放经验。
    4. 当前连胜 +1，同步历史最高连胜；按成功结算日期更新当天打卡。
    5. 读取更新后的当前连胜，计算 W，入账 clearXp = 20 × W；打卡系数不参与本关奖励。
    6. 经验入账后按第 04 节配置表更新等级与本级进度；将首通标记、对局处理记录、连胜、打卡、经验流水、新累计经验及等级结果一致提交；不改写已提交的登录奖励。
    7. 提交成功后刷新 Unity 界面并记录结算埋点；失败重试必须返回同一笔结果。

    未解锁图标置灰；等级位置显示“未解锁”当前值 / Lv1门槛达到Lv1后获得第一级并进入待领队列。
    已解锁正常图标；显示已获得等级，如Lv.1当前值 / 下一等级门槛达到下一等级继续升级与领取。
    已获得、待领取已获得等级立即保存，正常显示继续展示下一等级进度待领队列未确认前保留当前项。
    连续登录中断已获得图标和历史最高等级保留本轮进度从新的连续登录天数重新累计未达历史最高等级前，不重新领取旧等级。
    1. 卡片从上到下为成就名称、徽章图标、已获得等级、进度条。当前值／下一级目标值显示在进度条内部。
    2. 已获得等级取历史最高达成等级；进度条使用当前真实统计值及下一等级门槛。图标、底板、文字大小采用当前原型规范。
    3. 内容区超出一屏时上下滑动；页头、关闭入口与广告位不遮挡卡片。
    4. 领取成功后返回列表时可立即看到对应已获得等级；仅浏览列表不改变进度，不发奖励。

    05 · 获得与领取交互

    首页来源：有效登录

    1. 有效登录提交成功后，更新连续登录、累计登录的成就进度，并比较结算前后的已获得等级。
    2. 有新等级时，保存待领队列并在首页展示领取页；没有新等级时正常进入首页。
    3. 每次点击继续领取当前一项；全部领完关闭领取页，回到本次登录后的首页。

    结算来源：关卡成功

    1. 有效关卡结算提交后，更新每日十关、六角征程、一次过关、彩片清扫的对应进度。
    2. 先保存本关结算结果与新增成就待领队列，再展示成就领取页。领取期间不启动下一关。
    3. 全部领完返回同一局的联赛结算，段位、排名、金币和经验沿用本次已提交结果。
    4. 玩家点击结算页“下一关”才开始下一关；返回结算与成就领取均不再次发放通关奖励。

    领取页布局与操作

    位置文案 / 内容操作要求
    顶部“恭喜！”；“你的成就等级提升了”居中展示。
    中间第1项成就中文名称，如“六角征程”名称本身不附加等级。
    中间第2项成就徽章图形名称、徽章、等级一起左侧滑入、向左滑出；徽章下方另列等级。
    中间第3项Lv1、Lv2等不显示日期；获得日期仅在数据中保留。
    底部“点击继续”；有后续项时显示剩余个数徽章入场后再显示；出现后可点击画面继续，过渡和等待确认期间不响应重复点击。
    退出限制无关闭按钮外部点击、安卓返回键不跳过待领项。

    多个成就的顺序

    1. 不同系列按本需求第02节的固定顺序排列；同系列按等级升序排列。
    2. 一次只展示一项。还有待领项时，底部显示“还有N个成就待领取”；最后一项不显示剩余提示。
    3. 成就名称、徽章与等级从左侧滑入，约0.42秒完成；停留0.12秒后，再淡入“点击继续”及剩余个数。领取入口出现前不响应点击。
    4. 领取成功后，当前成就向左侧滑出，约0.28秒完成，再展示下一项的入场动画；最后一项滑出后返回原页面。过渡及等待确认期间不重复提交，快速连点不会跳过下一项。
    5. “获得”和“领取”分别记账：达到门槛即保存成就等级，领取成功只更新领取记录。

    06 · 数据保存与关联影响

    数据按账号隔离。以下名称用于说明现有数据语义，研发可映射项目内字段，不需要额外生成实现代码。

    触发 / 数据读取或保存关联影响与去重依据
    有效登录累计登录天数、本轮连续登录天数、最后登录日期仅更新连续登录和累计登录；账号＋自然日去重。
    新主线首通稳定关卡ID、对局ID、当天已通关不同关卡集合更新六角征程及每日十关；每关首通一次，每日十关最多贡献1次。
    首次尝试通关本关首次尝试标记、对局ID、满盘次数、复活次数满足首次尝试且无失败、无复活时更新一次过关；暂停、恢复同一局不新增尝试。
    有效消除结算对局ID、战斗提供的有效彩色片数量仅对未处理的完成对局增加彩片清扫；重复结算不再增加。
    各成就记录系列标识、当前统计值、历史已获得等级、获得日期当前统计值允许因断登归零，历史已获得等级不回退。
    待领队列唯一领取标识、系列、等级、来源、原对局ID来源为home或settlement；唯一标识包含账号＋系列＋等级，记录固定顺序。
    已领取记录已经确认领取的唯一标识集合重启、重试、跨日或版本更新均不重领；不同账号分别保存。

    同一事务中的处理顺序

    1. 校验有效登录或完成对局，识别账号、日期、稳定关卡ID及对局唯一ID。
    2. 检查事件是否已经结算；已结算返回首次结果，不再次增加进度。
    3. 更新受影响的成就统计与等级；为每个新增等级生成唯一待领项。
    4. 一致保存进度、已获得等级、待领队列及本次处理记录，再刷新界面。
    5. 领取请求以“账号＋成就系列＋等级”为唯一依据；确认成功后移出当前待领项并记录已领取。
